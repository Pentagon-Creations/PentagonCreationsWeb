# Pentagon Creations

**Pentagon Creations** is an independent creative studio focused on developing and showcasing digital creative works, including games, visual art, stories, and music.

This repository contains the source code for the official Pentagon Creations website.

## About the Website

The website serves as the studio's digital showcase, presenting its projects, creative works, news, and other published content.

### Main Sections

- **Featured Games** — Game projects and releases.
- **Story Books** — Written stories and literary works.
- **Art Gallery** — Visual artwork and illustrations.
- **Music** — Original music and audio projects.
- **What's On** — Studio news, announcements, and updates.
- **Our Creations** — An overview of the studio's creative work.

## Technology

- React
- Vite
- JavaScript
- CSS
- Sanity CMS

## Content Management

The website uses Sanity CMS to manage its published content.

The Sanity Studio is maintained separately from this repository. Website content is retrieved through the configured Sanity project and dataset.

## Deployment

The website is hosted using **GitHub Pages**.
